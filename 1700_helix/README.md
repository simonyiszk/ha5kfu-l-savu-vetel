# 1700 MHz-s hélixantenna

Az 1691 MHz-s adás vételéhez egy LHCP hélix szükséges mint primersugárzó. A notes.md tartalmazza a tervezés lépéseit. 

Eltérések a modell és a megépített verzió között:
- Az itt szereplő modell túl sok menetet tartalmaz, megépítés után kiderült, hogy nagyon alulvilágítja a parabolát, így a menetekből vágtunk, most kb. 3 menetes a hélix.
- A reflektort végül nem vágtuk nyolcszögletűre, meghagytuk a levágott négyet alakú NYÁK-ot. Egy bevágást készítettünk rá az először használt parabola LNB tartó karja számára.
- A megtáplálást a középpontról kihoztuk a kerületre, illesztésnek pedig egy kis darab FR4-et forrasztottunk a hélix első negyed menetéhez. 

A 3D modelleket a LEGO Kör nyomtatta ki számunkra PLA-ból. A kész antennát akrifestékkel festettük le, hogy időjárásállóbb legyen.
