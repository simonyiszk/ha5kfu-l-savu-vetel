# Parabola bilics tervek

A vételhez használt 120cm-es parabola bilincsei nem voltak jók a tervezett telepítési hely 75mm-es átmérőjű árbócához, ezért új bilincseket kellett csinálni a régiek alapján.

A bilincs két darabból áll: a kengyel és a bilincs, előbbit laposvas-darabokból, utóbbit acél körrúdból készítettük el. A felszerelés után a kengyelek kicsit el tudtak csavarodni, ezért beszereltünk plusz egy keresztmerevítőt is.
